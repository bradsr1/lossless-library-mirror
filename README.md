# Lossless Library Mirror

Docker app that losslessly converts ALAC music libraries into verified PCM WAV files.

## Download

[Download the ready-to-use converter ZIP](https://github.com/bradsr1/lossless-library-mirror/raw/refs/heads/main/lossless-library-mirror-fixed.zip)

The ZIP contains the Docker setup, web interface, converter, documentation and automated tests. Existing destination folders are supported; files are preserved and conflicting WAV files are never overwritten.
